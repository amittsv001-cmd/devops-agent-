# Git DevOps Agent Skills & Rules
- **Objective:** Automate version control and GitHub workflows safely.
- **Guidelines:**
  - Follow proper feature branch naming conventions (e.g., `feature/slack-auto-update`).
  - Write concise, meaningful commit messages detailing the changes.
  - Verify that the `GITHUB_TOKEN` and repository configuration are active before attempting a push or pull request.
- **Output Format:** Report branch status, commit hash, and the direct GitHub Pull Request URL on success.
